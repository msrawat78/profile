# Personal Portfolio Website — Project Brief

You can use the following as your project brief in VS Code with your AI coding agent. It consolidates the decisions, structure, content, and implementation plan.

## 1. Project objective

Build a professional personal portfolio website using HTML, CSS and JavaScript, developed locally in VS Code with AI assistance and hosted free on GitHub Pages.

The website should position you as an experienced individual consultant, practitioner and trainer—not just as the owner of a company.

Why a personal website? Some clients prefer to work directly with an experienced individual rather than engage a company. Your website should make it easy for them to understand your expertise, see your work, explore your training offerings and contact you.

## 2. Personal positioning

Use this as the initial positioning statement:

Independent Consultant · Trainer · Data & AI Practitioner

Suggested headline:

> Helping businesses solve problems with data, analytics and AI—and helping professionals build practical skills.

Highlight your:

* B.Tech and MBA qualifications.

* 20 years of professional experience.

* Consulting and hands-on project experience.

* Training, workshops and mentoring.

* Work across analytics, data engineering, data science and AI-enabled automation.

Keep your personal identity at the forefront. Mention Klaymatrix Data Labs as an associated business, but do not make it the main focus.

## 5. Design direction

Aim for a polished, professional, contemporary consulting portfolio.

* Primary colors: Blue `#0066FF`, green `#00FF84`, navy `#211951`.

* Hero: Dark navy background with a clear headline, short introduction and prominent calls to action.

* Content sections: Light or neutral backgrounds with clean typography and ample spacing.

* Layout: Responsive project cards, clear section hierarchy and mobile-friendly navigation.

* Visual style: Professional, technical and distinctive, without looking like a generic AI-generated website.

* Accessibility: Readable contrast, semantic HTML, keyboard-friendly navigation and meaningful image descriptions.

Avoid excessive animations, decorative icons, unsupported performance statistics, invented testimonials and long lists of technical buzzwords.

## 7. GitHub setup

Use your existing GitHub account.

1. Create a repository named `yourusername.github.io`, replacing `yourusername` with your actual GitHub username.

2. Build and test the website locally in VS Code.

3. Push the files to that repository.

4. Enable GitHub Pages in the repository settings.

5. Test the published website on desktop and mobile.

Your website will normally be available at:

`https://yourusername.github.io/`

You can add a custom personal domain later. A separate personal domain may be preferable if you want the portfolio to stand independently of Klaymatrix.

Also create or improve your GitHub profile README in a repository named exactly after your GitHub username. Keep it short, with your introduction, featured projects and links to your portfolio, LinkedIn and demos.

## 9. Implementation plan

Follow this sequence rather than asking the AI agent to build everything at once.

1. Prepare the content. Confirm your name, headline, contact links, resume and the 3–6 projects you want to feature.

2. Create the page structure. Ask the agent to build the semantic HTML sections and navigation first.

3. Develop the visual design. Add the responsive layout, colors, typography, project cards and mobile navigation.

4. Add real content and links. Connect your demos, repositories, LinkedIn, YouTube, Calendly and company website.

5. Test locally. Check mobile layouts, broken links, image loading, navigation, accessibility and the resume download.

6. Publish using GitHub Pages. Verify the live URL, then refine the content and design based on feedback.

Copy and paste the following into your coding agent:

Use HTML, CSS and vanilla JavaScript. The website must be responsive, accessible, fast-loading and suitable for free GitHub Pages hosting. Do not introduce a backend or framework unless there is a clear need.
